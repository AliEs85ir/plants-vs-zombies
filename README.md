## 🎮 Project Overview
This project is a comprehensive implementation of the acclaimed game **"Plants vs. Zombies"**. Our primary objective is to develop a robust, scalable, and object-oriented engine that simulates the strategic interactions between various plant species and invading zombie waves.

### Phase 0 Objectives:
In this foundational stage, we have meticulously designed the system's architecture to ensure high cohesion and low coupling. Key focus areas included:
- **Comprehensive Class Hierarchy:** Defining base abstract classes and interfaces for game entities to support extensibility (Open/Closed Principle).
- **Game Mechanics Modeling:** Abstracting complex interactions such as attack strategies, ability systems, and environmental effects.
- **Design Patterns Application:** Utilizing architectural patterns to manage the game state, UI transitions, and entity behaviors efficiently.
